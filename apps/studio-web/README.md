# Веб-комбайн S09

React/TypeScript: вход владельца, список и редактирование серверных черновиков,
сравнение открытой и текущей версий, конфликт 409 с сохранением локального текста.
Публикация контента не реализована. UI собирается `npm run build:studio-web`.

Для работы нужен HTTPS same-origin маршрут `/game/server/admin/v1` и размещение
UI под `/game/studio/`; развертывание и reverse proxy еще не настроены. Не
использовать рабочий портал VPS без предварительного обследования S51.
Проверка реального браузера/телефона пока не выполнена, S09 не завершен.
