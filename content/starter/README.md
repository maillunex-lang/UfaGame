# Стартовый мир для проверки

`ufagame-starter.zip` — готовый пакет для импорта в Studio (ug-content/1, без
картинок): 6 фракций (4 по кругу преимуществ + Свет/Тень), 21 способность (в том
числе условия срабатывания и дополнительные действия), 10 героев игрока, 10 врагов
и боссов, 7 предметов на 6 слотов, таблица развития (предварительные числа),
3 главы по 4 этапа с боссами на карте Уфы, Бурзянского и Белорецкого районов,
тренировочный этап, таблица VIP (10 уровней), призыв «Зов героев» (50 самоцветов,
гарантия Ильгиза или Сэрвэра раз в 10 попыток, осколки), AFK-награды, скорости боя
(×2 после 3 этапов, ×4 с VIP 4, быстрый расчёт повторов с VIP 7) и 6 заданий: 3 ежедневных
и серия достижений по кампании. Все персонажи и названия придуманы для игры; точки сюжета на
карте приблизительные (отмечены как ручные).

Игрок стартует с пятёркой (Азамат, Айгуль, Карагай, Зульфия, Тимер), лишними копиями
Азамата и Айгуль и Степной саблей; за первую победу — 500 самоцветов (10 попыток призыва). Остальные герои — награды за первые победы.

Сложность (уровень пятёрки, нужный для победы, по симуляции сервера) — `balance.json`:
глава 1 — 1–5, глава 2 — 7–13, глава 3 — 16–25 (для 25 нужен ранг «Воин»).

Пересобрать после правки `tools/content/starter-world.mjs`: `npm run build:starter`.
`npm run check` проверяет, что пакет актуален, а `tests/integration/starter-world.test.mjs`
импортирует его в новый черновик, публикует и проходит первый этап.

Импорт: Studio → «Черновики» → «Создать» → в новом черновике раздел «Импорт и экспорт
ZIP» → «ZIP-пакет» (выбрать файл) → «Проверить пакет» → «Применить импорт» →
«Публикация контента». В новый черновик пакет ложится без конфликтов.
