# Проверка комплекта
Дата: 2026-11-02. Проверяется комплект проектирования, не готовая игра.
## Объем
55 решений, 60 этапов, 60 отдельных промптов, общие промпты Game/Studio/Server/Continue, спецификации редакторов/жителей/обновлений/ZIP, демонстрационный пакет.
## Автоматические проверки
Команда: python3 tools/validate_planning.py
Проверяет число этапов и решений, наличие промптов, порядок зависимостей, относительные ссылки, синтаксис JSON и размеры/hash/ссылки/поля демонстрационного пакета.
Это специализированная статическая проверка образца, а не полный JSON Schema validator и не production ZIP importer.
Фактический запуск: exit code 0.
Результат: 60 этапов, 60 промптов, 55 решений, 2 файла в inventory примера; JSON и относительные ссылки корректны; зависимости ссылаются только на предыдущие этапы.
При подготовке обнаружено расхождение контрольных сумм из-за завершающих переводов строк; inventory пересчитан по окончательным байтам, повторная проверка прошла.
Полная проверка по JSON Schema отдельной библиотекой в этой среде не выполнялась (библиотека отсутствует); для примера выполнены явные проверки обязательных полей, типов, диапазонов и ссылок.
## Не проверено
- Сборка/установка/размер/подпись Game и Studio APK.
- Боевая симуляция, сервер/API/БД, публикации и компенсации.
- Работа ZIP в реальном комбайне и игре.
- SSH/VPS, нагрузка, домен, реальные платежи.
- Полная карта всех районов и финальные игровые ресурсы.
Все S01–S60 остаются todo. Публикация документации не делает их done.
