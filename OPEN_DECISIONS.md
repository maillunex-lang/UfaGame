# Открытые параметры перед реализацией
Не требуют повторного опроса по уже выбранным решениям. Если нет ответа, автономно готовить независящие части и явно записывать временные инженерные значения.

| Параметр | Когда нужен | Действие |
|---|---|---|
| Точные версии Godot/Node/React/PostgreSQL/JDK/SDK, minSdk, ABI | S01 | проверить официальные источники и прототипы, ADR и lockfiles |
| Телефон приемки, Android, целевые FPS/RAM | S01/S54 | определить контрольное устройство; не обещать непроверенный запуск |
| VPS SSH endpoint/user/port/host fingerprint, CPU/RAM/диск | S51 | запросить доступ непосредственно перед обследованием; не хранить секреты в git |
| Домен и DNS/TLS, маршрут сайта | S51–S52 | проверить существующий reverse proxy, подготовить отдельный маршрут |
| Целевой живой онлайн и бюджет | S54 | измерить емкость, нагрузки 1/10/50 как предложенные ступени, не обещание поддержки |
| Порог ×2, уровни/предел VIP, темп бесплатных очков | S25–S26 | таблицы настраиваемы; бесплатный VIP не упирается в конечные задания |
| Шансы/гарантии/цены/ранги/награды/сезоны | профильный этап | подготовить редактируемые стартовые таблицы, пометить как предложения |
| Конкретный район старта и сюжет | S22/S53 | предложить небольшой маршрут по проверенной географии, не считать выбором владельца |
| Источник геоданных и правовой режим ресурсов | S21 | записать происхождение, условия и атрибуцию; проверить актуальные источники |
| Лицензия исходников и игровых материалов | до внешнего релиза | публичность не назначает лицензию; не выбрать лицензию от имени владельца |
| Платежный провайдер/получатель/валюта/условия | S56 | сначала тестовый адаптер; не принимать реальные деньги без настройки |
| Срок хранения копий, место и оповещение | S50 | предложено 7 ежедневных + 3 предмиграционных с дисковым лимитом; не утверждено владельцем |
| Подпись APK и секрет подписи манифеста | S04/S10 | создать по правилам хранения, приватно сохранить и проверить восстановление ключа |
| Будущий ИИ API/бюджет и внешние копии | S58/S60 | отдельная настройка, не нужна шаблонным жителям |
