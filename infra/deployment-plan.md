# Будущее подключение API

Владелец указал144.31.254.99. Порт8055 — кандидат, не проверен и не зарезервирован.
S03–S07 не подключаются к VPS и не меняют firewall/proxy/services.

На S51 проверить read-only: занятые порты, действующие проекты/health,
CPU/RAM/disk, существующий reverse proxy и маршруты/TLS. Не занимать8055 до отчета.
На S52 API желательно bind127.0.0.1 на подтвержденном свободном порту,
наружу — отдельный HTTPS маршрут существующего proxy с diff/rollback.
Не открывать bare HTTP auth API всему Internet. DNS либо доверенный IP SAN
сертификат, автоматическое продление. Публичный API URL после проверки задается
в игре; сейчас поле намеренно пустое, пользовательские tokens не отправляются
на еще не настроенный адрес. При отсутствии proxy сначала отдельный согласованный
план, не занимать443 поверх чужого сервиса.


Владелец уточнил: tts-ufa.ru привязан к VPS и уже обслуживает рабочий портал
на стандартном порту. Не использовать root host как новый API, не заменять
его route/cert и не занимать80/443 поверх существующего сервиса. Снять baseline
health до любых изменений. Кандидат game-api.tts-ufa.ru — отдельный DNS/vhost,
еще не создан и не утвержден как готовый адрес. Изменение общего reverse proxy
только подготовленным diff с проверкой конфигурации, планом отката и baseline
рабочего портала до/после. Не выполнять установок/рестартов в S51.


Актуальный предпочтительный вариант владельца: https://tts-ufa.ru/game/server.
Для path-based маршрута новая DNS запись не требуется. Клиент поддерживает
base URL с path prefix. Проверить, что портал не использует этот namespace.
Upstream должен получать /v1/guests, /v1/progress и /health/ready после снятия
prefix /game/server/. Не применять новый маршрут к / или остальным paths.
API использует Bearer, не cookies портала; не добавлять portal-auth redirect
в этот prefix, не отключая защиту самого портала. Клиент не следует redirects
с credentials. Не считать TLS проверенным по одному наличию домена.
Точный diff только после определения nginx/Caddy/Apache/другого proxy в S51.
