# Первичные источники
Проверены при подготовке 2026-11-02. Перед реализацией проверить актуальные версии.
- Godot: пакеты, патчи и ограничения загрузки: https://docs.godotengine.org/en/stable/tutorials/export/exporting_pcks.html
- Godot: runtime loading: https://docs.godotengine.org/en/stable/tutorials/io/runtime_file_loading_and_saving.html
- Godot Android export: https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html
- Android FileProvider: https://developer.android.com/reference/androidx/core/content/FileProvider
- Android PackageInstaller: https://developer.android.com/reference/android/content/pm/PackageInstaller
- GitHub Releases ссылки: https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases
- GitHub release API: https://docs.github.com/en/rest/releases/releases
- OpenStreetMap источник и лицензирование: https://www.openstreetmap.org/copyright
Использование OSM - возможный источник, не готовая карта и не разрешение массово скачивать чужие тайлы. Отдельно проверить условия поставщика тайлов, атрибуцию и распространение производных данных. Технические и юридические требования площадок/провайдеров проверяются на этапе их подключения.
