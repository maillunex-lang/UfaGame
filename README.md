# Game / Game Studio - UfaGame

Онлайн-RPG для Android и комбайн управления — в разработке. Дата: 2026-11-02, Asia/Yekaterinburg.
Репозиторий: https://github.com/maillunex-lang/UfaGame

**Состояние: технический Android-прототип, строгие контракты, локальный API/PostgreSQL ledger и guest/login/recovery реализованы и тестируются. S01–S03 и S05–S07 приняты; S04 ждёт внешней приватной копии signing keys. S08 завершён: отдельная авторизация владельца, CSRF и атомарный аудит.** Это еще не готовая игра: боя, экономики контента и редактора Studio нет. VPS не обследован/не изменялся. [Команды S03–S07](docs/S03_S07_RUN.md).

## Начало работы

1. Прочитать AGENTS.md, PROJECT_SPEC.md, ARCHITECTURE.md и roadmap.md.
2. Открыть PROMPT_CONTINUE.md и первый доступный этап из roadmap.md.
3. Выполнить один доступный этап, проверить результат, обновить roadmap.md.
4. Отдельные задания: PROMPT_GAME_APK.md, PROMPT_STUDIO_APK.md, PROMPT_SERVER.md.
5. Для модификаций: MODDING_SPEC.md, PROMPTS_FOR_MODS.md, examples/README.md.
6. Для сборки, выпуска и VPS: OPERATIONS.md. Нерешенные параметры: OPEN_DECISIONS.md.

## Состав

- PROJECT_SPEC.md: все 55 решений, границы первой версии.
- roadmap.md: 60 этапов реализации с зависимостями, критериями готовности и статусами.
- PROMPTS_BY_STAGE.md и prompts/stages/: индекс и 60 отдельных промптов.
- EDITOR_MATRIX.md: редакторы, данные и действия.
- BOT_SPEC.md: жители с памятью, пока без языковой модели.
- CONTENT_AND_UPDATES.md: кэш, доставка контента, обновление APK.
- docs/reports/: фактические проверки реализации; VALIDATION_REPORT.md — исходная статическая проверка комплекта.
- SOURCES.md: первичные технические источники.
- examples/: пример структуры модификации и сценарии отказа.

## Принципы

Одна игра. Русский язык. Аниме-фэнтези Башкортостана. Собственные персонажи и оформление; AFK Arena - ориентир структуры, без копирования ресурсов.
Game APK до 95 МБ проверяется измерением. Скачанные ресурсы хранятся в постоянном каталоге приложения до ручной очистки; удаление приложения/его данных удалит и эти файлы.
Все изменения проходят черновик, проверку, предпросмотр и ручную публикацию.
Существующие проекты и занятые порты VPS не изменять.
Публичный репозиторий не означает автоматически выбранную лицензию; решение владельца пока открыто.
