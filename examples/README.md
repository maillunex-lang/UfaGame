# Примеры пакетов ug-content/1

- `ufa_batyrs_starter/` — рабочий пример: две фракции, две способности, герой с
  анимированным спрайтом (PNG 2 кадра), враг и этап. Тест `tests/mod/example.test.mjs`
  упаковывает каталог в ZIP, проверяет настоящим инспектором, строит план импорта в
  пустой черновик `draft_001` и проводит бой по этапу. Для импорта в Studio упакуй
  содержимое каталога (не сам каталог) в ZIP.
- `hello_bashkortostan/` — старый образец шаблона диалога жителя. Требует capability
  `dialogue.template.v1`, которой еще нет, поэтому импорт отклоняется с понятной
  ошибкой — это ожидаемое поведение до этапа S40.

Как готовить свои пакеты (в том числе другим ИИ): docs/MOD_AUTHORING.md.
