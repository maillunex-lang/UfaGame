# Пример модификации
examples/hello_bashkortostan/ - образец структуры ug-content/1.
Добавляет шаблон диалога жителя в общий чат. base_content_version="demo-1" - демонстрационная база, не существующая опубликованная версия.
Файл dialogue_template.schema.json описывает только тип примера; это не полный реестр игры.
Пакет hello_bashkortostan.zip создается при подготовке комплекта, лежит в архиве поставки; source-структура и контрольные суммы доступны в репозитории.
Проверка static: JSON, size/hash, inventory, source/id и schema. Не подтверждает работу несуществующего игрового импортера.
Для реального применения экспортировать текущую базу/capabilities, заменить base и обновить hash измененных файлов.
Сценарии отказа: измененный байт operations, ../ путь, неизвестная capability, отсутствующий source, конфликт create, неподтвержденное delete правило. Эти сценарии должен отвергать production-валидатор S13, а не только документация.
