# S07 — привязка, пароль и recovery

2026-11-02 UTC. Backend реализован/проверен; общий статус done после Android-приемки и реального Godot HTTPS/PostgreSQL smoke. Исходный commit8a4308d.
Миграция003: уникальный normalized login, scrypt hash, recovery hash и constraints.
Migration004 сохраняет guest identity после долгого отсутствия (generation renewal),
не обходя revoke/bind; старые migration файлы не переписывались.
Схемы bound_session/rotate_recovery_request и ADR0002/0004 обновлены до кода.

Сервер: bind сохраняет player_id/баланс, отзывает guest sessions; login проверяет
scrypt N131072/r8/p1 (max2 concurrent, bounded queue16), salt16B, timing-safe compare.
Recovery32random bytes, SHA256 в БД, одноразовая смена password/code + revoke всех
старых sessions одной транзакцией. Login normalization ASCII lower, unique DB
constraint и player row locks. Lost-response recovery: login новым паролем и
password-protected rotate_code. API не логирует request bodies/секреты.

`npm run test:integration`: 11pass на ephemeral PostgreSQL18.4,
дважды migrations. Матрица: rollback после ledger write (и balance/ledger пусты),
dedupe/overspend/fencing, реальный loopback HTTP health, health503, body413,
два гостя, retry/expiration/revoke, inactive guest renewal без нового player,
гонка одинаковых логинов (200/409), неправильный код, гонка одного recovery
(200/401), старый код не повторяется, старые sessions и password не действуют,
rotation recovery code, отсутствие plaintext credentials в rows и login429.
Лог: /workspace/scratch/s07-final-evidence.log. Повторные CI результаты добавляются
после push. `npm run check`: exit0, включая contracts6pass, gitleaks и typecheck.
