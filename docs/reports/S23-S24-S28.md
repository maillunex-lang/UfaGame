# Пакет S23 + S24 + S28 — развитие героев, пятёрка и синхронизация, экипировка

Статус: реализация и автоматические проверки готовы; приемка на телефоне — после
обновления VPS (миграция 013) и Game v13. ADR 0021.

## Сделано
- Контракт: `progression`, поля `item` и `stage`, capability `heroes.progression.v1`,
  правила `progressionProblems`, схемы запросов (`hero_*_request`, `item_*_request`),
  ответа `heroes`, `battle_start_request.instance_ids`.
- API `services/api/src/heroes.ts`: `GET /v1/heroes` (стартовые герои один раз, план
  ранга, цены), `POST /v1/heroes/level|rank|team|protect`, `POST /v1/items/equip|upgrade`;
  бой своими героями (live и мгновенный), награды героями/предметами/опытом/материалами.
- Studio: раздел «Развитие героев и предметы» (таблица с предлагаемыми значениями,
  ранги добавить/убрать, стартовые герои по количеству, предметы 6 слотов, редкость,
  бонусы, улучшения, фракции); этап — опыт/материалы/герой/предмет в награду, уровень врагов.
- Game: «Мои герои» — уровень +1 с ценой, ранг с планом «копий X из Y + материалы»,
  в пятёрку/в синхронизацию, защита, предметы «Надеть/Снять/Улучшить»; бой основной пятёркой.
- `infra/studio-test/update.sh` — обновление тестового стека одной командой с
  резервной копией и автооткатом.
