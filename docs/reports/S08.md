## Реализовано
Migration005: отдельные owner_accounts singleton(id1), owner_sessions,
owner_audit с before/after/actor/reason/request_id, append-only triggers.
Строгие shared schemas owner login/profile/logout/password/query/session/audit.
CLI owner:create читает private regular0600 file без symlink/echo пароля,
отказывает при повторном provisioning, нет публичного signup/default credentials.
Owner API изолированы /admin/v1, не принимают player bearer или player cookie.

Cookie __Secure-ufagame-owner, Secure/HttpOnly/SameSiteStrict/host-only,
public Path=/game/server/admin/v1, hard TTL30min, только hash в DB.
Fail-closed503 до явного HTTPS ADMIN_ORIGIN. Exact Origin на mutations,
CSRF token из login/session JSON, constant-time check, no-store, без CORS allow.
GET не меняет state. Duplicate cookie names отклоняются.
Profile display_name/revision — реальная mutation, не игровой прогресс;
optimistic locking и request_id dedupe (replay не создает еще audit).
Logout/revoke-all/password change audited, password change отзывает sessions.
Audit snapshots не содержат hashes/tokens/password/CSRF. Audit и effect атомарны.
ADR0005 фиксирует ограничения same-origin portal/XSS и DB superuser.
