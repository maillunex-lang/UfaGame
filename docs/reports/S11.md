# S11 — подготовка проверки ресурсов

Статус in_progress. Добавлен packages/content-validator/png.mjs: проверка сигнатуры,
CRC, структуры чанков, границ размеров и распаковки строк ограниченного
8-битного нечересстрочного подмножества PNG. Неподдерживаемые критические чанки
и форматы отклоняются. Тесты проверяют корректный образец, неверную сигнатуру,
CRC, обрезание, превышение размеров, неверный фильтр и превышение распаковки.

Это подготовка: валидатор не выполняет полную реконструкцию изображения, не
запускается в изолированном процессе и не подключен к ZIP, API или редактору.
Реестр ресурсов, сохранение, другие форматы, лицензии, анимации, кадры, точки
крепления и preview не реализованы. ZIP инспектор продолжает отклонять любые
ресурсы до завершения их безопасной обработки. Пользовательский импорт в этой
версии недоступен; S11 не done. Далее реализовать изоляцию декодирования,
ограниченный реестр и доступный редактор, затем завершить S12–S14.

## Аудио в API/UI, ссылки контента и спрайты (commit 1dfef30)

- `resource_descriptor` — изображение (PNG, кадры/anchor/scale) или звук (PCM WAV:
  длительность, частота, каналы, разрядность); тип определяет дочерний процесс по
  сигнатуре байтов. Для звука кадры при загрузке и PATCH отклоняются (422
  `AUDIO_FRAMES_UNSUPPORTED`). Данные отдаются с собственным Content-Type,
  `nosniff` и CSP `sandbox`.
- Контент: `hero.data.sprite_resource_id` (только PNG), `ability.data.sound_resource_id`
  (только WAV), capability `content.resources.v1`. При сохранении черновика сервер
  в той же транзакции проверяет существование и тип каждого ресурса (`FOR SHARE`);
  ошибка — 422 `RESOURCE_REF_INVALID:<id>`, черновик не меняется.
- Studio: загрузка PNG/WAV, проигрыватель звука, поля ссылок в формах, спрайт героя
  (с анимацией кадров и зеркалом у защитников) в повторе боя.

Проверки: `npm run check` exit0; `check:mod` 22 passed; `check:studio` 7 passed;
мобильный Chromium (mock API + настоящий battle-core): WAV и проигрыватель, ссылка
на спрайт, спрайт в повторе — passed. Интеграция с реальной PostgreSQL 16.15 и
Chromium: 24/25, провал только Godot (ENOENT, нет бинарника). Новый тест: WAV с
кадрами 422, корректный WAV, Content-Type/nosniff, PATCH 422, черновик без capability
400, отсутствующий ресурс/неверный тип 422, корректные ссылки 200.

Критерии S11 по автоматическим доказательствам: ресурс виден в редакторе с кадрами
и ссылками; объемы ограничены (8 МиБ/файл, 128 шт., 32 МиБ, 120 с звука, 4096 px,
120 кадров); тип не по расширению; поврежденное изображение/звук, превышение,
отсутствующий/выходящий кадр и цикл анимации проверены. Ограничения: форматы только
PNG и PCM WAV; изоляция — дочерний Node с лимитами памяти/времени и файловым
permission, не контейнер ОС; удаление ресурсов не реализовано; в игре ресурсы
появятся в S16/S19. На VPS (веб и API) и на телефоне эта версия не проверена.
