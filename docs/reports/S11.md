# S11 — подготовка проверки ресурсов

Статус in_progress. Добавлен packages/content-validator/png.mjs: проверка сигнатуры,
CRC, структуры чанков, границ размеров и распаковки строк ограниченного
8-битного нечересстрочного подмножества PNG. Неподдерживаемые критические чанки
и форматы отклоняются. Тесты проверяют корректный образец, неверную сигнатуру,
CRC, обрезание, превышение размеров, неверный фильтр и превышение распаковки.

Это подготовка: валидатор не выполняет полную реконструкцию изображения, не
запускается в изолированном процессе и не подключен к ZIP, API или редактору.
Реестр ресурсов, сохранение, другие форматы, лицензии, анимации, кадры, точки
крепления и preview не реализованы. ZIP инспектор продолжает отклонять любые
ресурсы до завершения их безопасной обработки. Пользовательский импорт в этой
версии недоступен; S11 не done. Далее реализовать изоляцию декодирования,
ограниченный реестр и доступный редактор, затем завершить S12–S14.
