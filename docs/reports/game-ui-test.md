# Интерфейс Game для удобства тестирования

По просьбе владельца длинный технический экран разделён на вкладки «Карта»,
«Герои», «Задания», «Награды» и «Настройки». Адрес сервера, загрузка ресурсов и
управление аккаунтом сохранены в настройках; карта и запуск боя остаются в игре.
Добавлены единые цвета и оформление кнопок. Механика и сервер не менялись.

Godot 4.6.3: `npm run check:game`, `godot --headless --path apps/game --script
res://test_ui.gd` — переходы между пятью разделами и адрес сервера проверяются
автоматически. Фактическая компоновка, безопасные поля Android и читаемость на
телефоне ещё не проверены. Это тестовый интерфейс, не законченная графика игры;
S31 по-прежнему in_progress. Сервер и игровая экономика не обновляются.
