# S19 — визуализация боя в Game

Статус: in_progress — реализация и автоматические проверки на настоящем Godot
выполнены; нужна проверка на Android (бой/команда/сеть) после развертывания на VPS.

## Реализация
- `apps/game/live_client.gd`: старт или продолжение боя (`/v1/live-battles/active`),
  WebSocket с bearer только в заголовке, порядок кадров через `live_replay.gd`
  (повторы/пропуски), переподключение с курсора (1,2,4,8 с; обновление токена),
  после перезапуска приложения — досмотр пропущенных кадров с сохраненного курсора,
  команды «способность»/«авто» с монотонным seq (переживает перезапуск), сверка
  показанного итога с серверным снимком (hp/x/y/energy и результат), запасной HTTP.
- `apps/game/battle_view.gd`: вертикальный экран — враги сверху, команда снизу,
  плавное движение (lerp за 100 мс), полоски HP, всплывающие урон/лечение/оглушение/
  отбрасывание, отметка оглушения; портреты своих героев с HP и энергией (готовый —
  подсвечен), нажатие — основная способность; кнопки «Авто» и «Выйти»; окно итога
  «Победа/Поражение» и «Итог сверен с сервером ✓».
- `apps/game/main.gd`: раздел «Бой» — этап списком, герои галочками (до 5),
  «В бой!» / «Продолжить бой».
- Studio: тип объекта «Этап (бой в игре)» — противники галочками (1–5), 90 с.
- Сервер (ADR 0017, дополнение): ожидание готовности нажатия до 1 с, перенос
  опоздавших до 1 с команд, отложенное закрытие потока, `GET /v1/live-battles/active`.
- nginx: `infra/studio-test/render-websocket.py` + `apply-websocket.sh`.

## Проверки
- `tests/integration/godot-live.test.mjs` — настоящий Godot 4.6.3 через TLS-фронт с
  проксированием WebSocket: бой создан; раннее нажатие получает ответ сервера; при
  дистанции удара ручная способность применена; «Авто» подтверждено кадром; обрыв
  соединения — переподключение и продолжение; «перезапуск» — новый клиент нашел тот
  же бой, курсор не откатился; бой завершен; показанное состояние совпало со
  снимком сервера; все кадры 1..N показаны без пропусков; окно итога. 4 прогона
  подряд — без ошибок.
- `npm run check:battle` 38 (в т.ч. ожидание готовности, перенос опоздавших команд),
  `live-battles.test.mjs` 6 (в т.ч. active), полная интеграция 36/36, `npm run check`,
  `npm run check:game`, Chromium mobile (этап в Studio).
- nginx 1.24.0 (как на VPS): текущая конфигурация — WebSocket не проходит (HTTP 404),
  с `render-websocket.py` — снимок и кадры живого боя приходят.
- Скриншоты экрана боя под Xvfb (540×960): поле, полоски, всплывающие числа, портреты,
  окно итога.

## Не проверено
Android: бой, нажатие портрета, «Авто», обрыв сети на телефоне; внешний WSS через
nginx VPS; анимации спрайтов по кадрам атласа (сейчас первый кадр); ускорение
воспроизведения (живой бой идет в темпе сервера, пропущенные кадры досматриваются).
