# Пакет S25 + S27 + S29 — VIP и обучение, призыв, AFK-награды

Статус: реализация и автоматические проверки готовы; приемка на телефоне — после
обновления VPS (миграция 014) и Game v14. ADR 0022.

## Сделано
- Контракт: `vip`, `summon_pool`, `afk`, capabilities `vip.v1`, `summon.v1`, `afk.v1`,
  правила `economyProblems`, схемы запросов и ответов (`vip`, `summon`, `afk`).
- API `services/api/src/economy-routes.ts`: `GET /v1/vip`, `POST /v1/vip/daily`,
  `POST /v1/tutorial/claim`, очки VIP за победы (суточный предел) в шаге боя;
  `GET/POST /v1/summon`, `POST /v1/summon/assemble`; `GET /v1/afk`, `POST /v1/afk/claim`.
  Миграция 014 (счётчики гарантии, сохранённые результаты призыва, окно AFK, ответы получения).
- Studio «VIP, призыв и AFK-награды»: таблицы с предлагаемыми значениями, «дней до
  уровня бесплатно», призыв с весами → процентами, осколками и гарантией.
- Game: AFK (накоплено/забрать), VIP (очки, ежедневные, обучение по шагам), призыв
  (шансы, гарантия, ×1/×10, результаты, сборка из осколков). request_id хранится до
  ответа сервера — повтор после обрыва не платит дважды.
- Стартовый мир: таблица VIP, «Зов героев», AFK, 500 самоцветов за первую победу.

## Проверки (2026-11-03; Node 24.22.1, PostgreSQL 16, Godot 4.6.3, Chromium)
- `npm run check` exit 0: contracts 19 (неверные веса/дробные, герой вне пула в гарантии,
  осколки без рецепта, дубли, пороги VIP не растут, обучение ниже VIP 1, нет бесплатного
  источника, AFK в самоцветах, capability; формулы VIP/шансов/гарантии/единиц AFK), studio 17.
- Интеграция на чистой PostgreSQL 47/47. `economy.test.mjs`:
  S25 — обучение закрыто до реальных шагов, выдаётся один раз; ежедневные очки при двух
  параллельных запросах — один раз; очки за победы до предела; смена таблицы
  пересчитывает уровень от тех же очков; огромный порог; клиент не может задать VIP.
  S27 — нехватка без записи; шансы 20/20/40/20; ×10 и повтор request_id (оплата один раз,
  тот же результат, другой count — отказ); 3 параллельные ×10; граница гарантии (нет
  3 подряд без гарантированного); осколки и сборка, нехватка осколков; счётчик сохраняется
  при смене контента и делает следующую попытку гарантированной.
  S29 — только серверное время; 2 ч → ~7200; параллельные получения — второе почти пусто;
  повтор request_id — тот же ответ; предел 12 ч; VIP +2 ч; победа делит интервал (1 ч старой
  ставки + 1 ч новой); новая версия делит интервал по времени публикации.
- Настоящий Godot (`godot-economy.test.mjs`): загрузка экрана, двойное нажатие AFK,
  ежедневные очки и отказ повтора, ×10, повтор с сохранённым request_id без оплаты,
  сборка из осколков. Стартовый мир: импорт → призыв ×10, VIP-обучение, AFK.
- Скриншоты Studio и Game осмотрены.
