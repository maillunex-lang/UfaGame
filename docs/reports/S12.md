# S12 — подготовка контракта ZIP

Статус blocked: обязательный S11 (реестр ресурсов и анимаций) не завершен.
Подготовлены предварительные структуры mod_manifest/mod_operations и ADR 0008.
Они проверяют типы, известные операции, поля, допустимые пути и формат hash, но
не проверяют фактический ZIP. `npm run check:contracts`: 9 тестов passed,
включая структурный пример, отказы traversal/произвольного кода и неизвестной
операции. Демо-пример требует неизвестную текущему реестру capability; он не
импортируется. Не реализованы распаковка/карантин, проверка hash содержимого,
разрешение зависимостей, семантическая совместимость, сохранение, UI и S11.
Схема предварительная; ни одну capability импорта не объявляем.
Дальше: завершить S11 и безопасную проверку ZIP S13, затем транзакционный S14.
