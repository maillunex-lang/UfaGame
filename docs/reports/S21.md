# S21 — геоданные и иерархия Башкортостана

Статус: done (данные, контракт, Studio). Показ карты в Game — S22. ADR 0018.

## Источник и проверка
- Wikidata (CC0), получено 2026-11-03T09:20:45Z: 63 объекта (54
  муниципальных района, 9 городских округов) + республика; сырой ответ
  `content/geo/wikidata-raw.json` SHA-256 d46d95999a3fad7645bc26a6af16933c5a360cb2c4f2b7ff7208f65a0ee778eb.
- Сверка с OpenStreetMap Nominatim: 63/63 — название совпадает и точка внутри рамки
  границы района/города по OSM; наибольшее расстояние до центра объекта OSM 36,6 км.
  Отчет `docs/reports/S21-geo-check.json`.
- Найдена ошибка Wikidata: точка Фёдоровского района (54,689; 56,136) находится
  около Уфы, в 187 км от района; использована координата центра (Фёдоровка), исходная
  сохранена в `source.corrected`. Белорецкий район сначала не нашелся из-за поиска
  (Nominatim вернул республику) — с точным запросом совпал.

## Реализация
Контракт `location` и `stage.location_id` (capability `world.locations.v1`), правила
`locationProblems`; ZIP-операции и экспорт с зависимостями мест. Studio: раздел
«Карта Башкортостана» — добавление 64 мест одной кнопкой, схема республики (районы —
кружки, города — квадраты), переход в район (нажатием или списком), точка нажатием
на карту района (координаты, расстояние до центра), правка и удаление точек, этап
привязывается к точке списком «Место на карте», художественная карта — PNG фон и
расстановка мест нажатием с явной подписью «рисунок, не координаты». Найдено и
исправлено: сохранение черновика ограничивалось 16 КБ — черновик с картой (~30 КБ)
не сохранился бы; для черновиков лимит 2 МиБ.

## Проверки
- `npm run check:contracts` 14: набор валиден (1+54+9, уникальные id, источники,
  башкирские названия, Уфа около 54,73° с. ш. 55,95° в. д., исправление отмечено),
  отчет OSM 63/63, иерархия, пропавший родитель, вне республики, слишком далеко,
  дубликат республики, этап на районе/удаленной точке, нет capability.
- `npm run check:studio` 13: повторный импорт ничего не добавляет, точка, ошибки
  точки, этап только на точке, удаление связанных мест запрещено.
- Chromium mobile (mock): импорт 64 мест, переход в Бурзянский район, точка нажатием,
  этап на точке, возврат к республике, художественная карта, без горизонтального
  overflow.
- Интеграция с реальной PostgreSQL 37/37: сервер принимает набор с точкой, отвергает
  потерянного родителя, точку в 150+ км, отсутствие capability; тело >2 МиБ — 413.
- `npm run check` exit0.

## Не проверено

районов как полигоны не используются (только центры и правило 150 км).
