# S16 — Game: вход, загрузчик и постоянные ресурсы

Статус: in_progress — реализация и автоматические проверки на настоящем Godot
выполнены; проверка на Android-телефоне (Game v8) после развертывания S15 на VPS
не проведена.

## Реализация
- `apps/game/content_client.gd`: `GET /v1/content/current` с capabilities клиента
  и ETag (304 — без повторной загрузки); проверка формы комплекта; ресурсы по
  SHA-256 в `user://content/blobs/<sha256>`; загрузка кусками по 256 КиБ через
  `Range` в `<sha256>.part` (после обрыва — докачка с размера `.part`); проверка
  SHA-256 перед переименованием; поврежденный файл удаляется и скачивается заново;
  бюджет хранилища (по умолчанию 512 МиБ) и обработка ошибок записи; новый комплект
  записывается в `active.json` атомарно (tmp + rename) только после загрузки всех
  первичных ресурсов (PNG), до этого действует прежний; без сети — работает
  сохраненная версия; несовместимый комплект (409) не применяется. Трассировка
  действий (`bundle_not_modified`, `blob_reuse`, `blob_download`, `blob_resume`,
  `activate`...) для проверок.
- Первичный пакет — изображения; «Скачать всё» — также звуки и прочие файлы.
- `apps/game/main.gd`: русский экран (приветствие, адрес сервера по умолчанию
  `https://tts-ufa.ru/game/server`, «Играть (вход гостем)», прогресс, понятные
  сообщения об ошибках), список героев со спрайтами из локального хранилища,
  «Скачать всё»; раздел аккаунта S06/S07 сохранен.
- Сервер: `/v1/content/blobs/:sha256` поддерживает один диапазон `Range` (206/416).
- `tools/android/build.sh`: режим `UFAGAME_GAME_ONLY=1` (Game без пересборки Studio).

## Проверки
- `tests/integration/godot-content.test.mjs` — настоящий Godot 4.6.3 headless против
  API с PostgreSQL за TLS-фронтом: первая загрузка и активация; перезапуск без
  загрузок (304 + reuse); «Скачать всё» докачивает звук; испорченный файл заменен;
  обрыв на втором куске → ошибка, версия не активирована, `.part` есть, финального
  файла нет → новый запуск докачал с 4096 байт, первый кусок не скачан дважды
  (журнал Range фронта); подмена байта → HASH_MISMATCH, `.part` удален, версия не
  активирована, повтор успешен; бюджет 1 КиБ → STORAGE_FULL, прежняя версия;
  несовместимая capability → INCOMPATIBLE_CLIENT, прежняя версия. `GODOT_CONTENT_OK failures=0`.
- Полная интеграция в этой среде: 28/28 (вместе с Godot auth); `npm run check` exit0;
  `bash tools/s01/check.sh` — S01 тесты и 300 кадров main без ошибок.
- Скриншот главного экрана под Xvfb (OpenGL llvmpipe) с подложенным комплектом:
  русский текст, герой со спрайтом, счетчик нескачанных файлов.
- Game v8: `UFAGAME_GAME_ONLY=1 tools/android/build.sh 8`, 25 985 811 байт (≤95 МБ),
  arm64, сертификат e8959e0f…e575 совпал с Game v7.

## Не проверено / ограничения
- Android-устройство: установка v8 поверх v7, `user://` на телефоне, реальная сеть.
- Реальное переполнение диска ОС (проверен бюджет и путь ошибки записи, не сам диск).
- Обучение (туториал) — только приветственный текст; полноценное обучение — S25.
- На VPS нужны миграция 009 и опубликованная версия, иначе игра покажет «Мир ещё не
  опубликован».
