## Серверные операции
Реализованы POST/GET /admin/v1/drafts и GET/PUT /admin/v1/drafts/:id.
Операции требуют owner session; запись требует Origin и CSRF. Создание и
сохранение проверяют общую content schema, записывают before/after, actor,
reason и request_id в owner_audit в той же транзакции. Повтор идентичного
request_id возвращает прежний результат; другой payload или устаревшая revision
получает 409 без перезаписи. Публикации и изменения игры нет.

Проверки: `npm run check:api` exit0; `npm run check:contracts` exit0;
`npm run test:integration` exit0, 21 test: миграции дважды, доступ без owner,
CSRF, создание, повтор/измененный повтор, гонка сохранений 200/409, чтение и
before/after audit. PostgreSQL временная, VPS не использовался.

S09 остается in_progress: веб-интерфейс, diff и проверка на телефоне не готовы.
