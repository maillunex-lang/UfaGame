# Исправление восстановления команд боя

Сообщение владельца: Game v16 показывает STALE_COMMAND, бой невозможно нормально
завершить. Найдена ошибка клиента: он увеличивал номер команды до подтверждения,
поэтому отклонённая команда могла оставить все последующие вне последовательности.
Клиент отправляет только одну неподтвержденную команду, записывает номер после ack,
после задержки переподключается и получает актуальный номер от сервера. Последний
известный клиенту номер при возобновлении не заменяет серверный. При отсутствии
кадров 8 секунд запускается переподключение. Ошибки показаны понятным текстом.
Игровые правила и сервер не менялись.

Настоящие PostgreSQL 17 и Godot: `node --test tests/integration/godot-live.test.mjs`
проверяет намеренно устаревшую команду, отказ, переподключение, повтор команды,
авто, ручную способность, завершение и сверку результата (1/1). Godot check:game;
полная проверка `npm run check` и CI выполняются. Исходное поведение на телефоне и
выход после исправления пока не подтверждены. VPS не обновлялся.
