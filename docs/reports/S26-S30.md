# Пакет S26 + S30 — скорости боя и быстрый расчёт, задания

Статус: реализация и автоматические проверки готовы; приемка на телефоне — после
обновления VPS (миграция 015) и Game v15. ADR 0023.

## Сделано
- S26: поля `speed_x2_stages`, `speed_x4_level`, `instant_level` в таблице VIP
  (capability `battle.speed.v1`); команда `speed` в очереди живого боя, право проверяет
  сервер (`SPEED_NOT_ALLOWED`), такт 100/50/25 мс, всегда 900 шагов; окно опоздания
  команд и частота отправки кадров растут со скоростью; быстрый расчёт `/v1/battles`
  только для VIP ≥ уровня и уже пройденных этапов кампании. Game: кнопки ×1/×2/×4
  в бою, «Быстрый расчёт» у пройденных этапов.
- S30: контент `quest` (capability `quests.v1`), события сервера с уникальными ключами
  (победа, прохождение, уровень, ранг, призыв, AFK, улучшение предмета), прогресс по
  периодам (сутки Уфы / один раз), серии, награды валютой и героями; правило
  «цель достижима» (этап проходится впервые один раз). Миграция 015.
  Studio «Задания и достижения»; Game — экран заданий с прогрессом и «Забрать награду».
- Стартовый мир: скорости и 6 заданий.

## Проверки (2026-11-04; Node 24.22.1, PostgreSQL 16, Godot 4.6.3, Chromium)
- `npm run check` exit 0: contracts 20 (скорости без capability, условия заданий,
  недостижимая цель, цикл серии, неизвестное событие), studio 18, battle 42.
- `tests/battle/speed.test.mjs`: живой бой в авто и быстрый расчёт с тем же seed дают
  одинаковый итог и HP; ×2/×4 не меняют бой; скорость действует с указанного шага.
- Интеграция `speed-quests.test.mjs`: ×1 на старте, отказ ×2 до прогресса, ×2 после этапа,
  ×4 по VIP — ~40 шагов в секунду, таймаут ровно 900 шагов (90 игровых секунд) примерно
  за 22,5 с; быстрый расчёт — отказ без VIP, отказ для непройденного этапа, клиент не может
  прислать итог, повтор пройденного этапа считает сервер. Задания: событие одной победы,
  записанное дважды параллельно, считается один раз; закрытая серия не копит прогресс;
  награда один раз при двух параллельных запросах; получение после «переподключения»
  (новый экземпляр API); серия открывается после награды; вчерашний ежедневный прогресс
  не получить; удалённая цель и цикл серии — недопустимый контент.
- Настоящий Godot (`godot-speed.test.mjs`): кнопки скоростей, сервер переключил ×4, бой
  до 900 шагов за < 35 с, итог сверен; задание → «Забрать награду», серия открылась,
  повтор отказан; кнопка быстрого расчёта только у пройденного этапа.
  Найдена и исправлена ошибка клиента: числа из JSON приходят дробными, кнопка ×4 была бы
  неактивной.
- Полная интеграция на чистой БД: 50/50 четыре прогона из пяти. Один прогон до правки
  тестов упал на S27 (подробности не сохранились); причиной нестабильности были бои,
  оставленные Godot-тестами, — теперь все такие файлы завершают свои бои. После правки
  два полных прогона подряд 50/50.

## Не проверено
VPS и телефон.
