# S06 — гости и сессии

2026-11-02 UTC. Статус blocked только по Android runtime приемке secure credentials.
Backend реализован: migration002, auth.ts, /guests/progress/refresh/revoke.
Opaque tokens256bit, только SHA256 в PostgreSQL, TTL15min/30days.
Bootstrap retry не создает второго игрока; после rotation/revoke не выдает
новые tokens. Refresh request_id позволяет30сек retry того же потерянного
ответа, другой request_id со старым токеном401. ADR0004 и schema обновлены до кода.

`npm run check:api`, `npm run test:integration`: exit0, 6 tests,
включая S05 regression, два гостя, hashes-only storage, progress isolation,
access/refresh expiry, rotation race, lost-response retry, revoke и rate limit.
На rate limit тест выявил500 вместо429; error builder исправлен, повтор pass.
`npm run check:game`: exit0, parser/startup и прежние store/replay проверки.

Android plugin CredentialsPlugin: AndroidKeyStore AES256/GCM, no_backup files,
temp+fsync+rename, ошибки decrypt не создают молча нового гостя. Plaintext
fallback отсутствует. UI принимает только HTTPS, сохраняет bootstrap и pending
refresh ID до network request; network errors не стирают credentials.
Доверенный v2 plugin компилируется javac/D8, вставляется в manifest/classes2.dex,
zipalign16KiB и повторно подписывается прежним Game key. В APK проверены metadata,
INTERNET и classes2.dex; apksigner/zipalign exit0. Patch допускает только известный
XML pool без styles и не допускает повторную инъекцию. Godot исходники v4.6.3
plugin registry проверены для metadata prefix.
Команда: bash tools/android/build.sh 3 с прежними PRIVATE signing env.
