# ADR 0024: безопасный состав экранов игры (S31)

Статус: проектируется; в опубликованных мирах не применяется. Приоритет первой
играбельной версии — карта, бой, герои, развитие и задания; редактор экранов,
чат и социальные системы отложены. Этот ADR не объявляет S31 реализованным.

Экран описывается ограниченным списком узлов: контейнеры column/row, надпись и
кнопка. Корень один, не более 40 узлов и 8 уровней, каждый дочерний узел имеет
одного родителя-контейнер; циклы, висячие ссылки, повтор идентификатора и
неизвестные поля отклоняются. Порядок элементов задан порядком массива.
Текст ограничен, привязки и действия выбираются из закрытых списков. Никакого
кода, URL, произвольных вызовов методов, игровых изменений или выдачи наград в
layout нет. Кнопки открывают уже существующие экраны; любые действия с прогрессом
остаются за существующим серверным API.

Контракт `game_layout` пока подготовительный: его нельзя добавлять в мир или
объявлять capability клиентам, пока не реализованы валидатор публикации,
отображение в Godot, fallback, интеграционные проверки и новая подписанная APK.
Редактирование без ручного JSON и проверка на телефоне — отдельные задачи S32.
