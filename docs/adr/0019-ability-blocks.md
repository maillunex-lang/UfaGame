# ADR 0019: блоки условий и действий способностей (S20)

Статус: принято. Capability `battle.triggers.v1`.

- `ability.data.trigger` (для неосновной, автоматической способности):
  `interval` (по умолчанию: прежнее правило шага кратного перезарядке),
  `self_hp_below` и `ally_hp_below` с обязательным `percent` 1–99,
  `battle_start` (один раз за бой при первом контакте). Условные блоки срабатывают,
  когда условие верно и прошла собственная перезарядка способности (`auto_state.next`).
  Основная способность по-прежнему работает от энергии/нажатия портрета.
- `ability.data.extra_effects` — до 2 дополнительных действий (damage, heal, stun,
  knockback, своя цель); применяются в том же шаге одновременно с основным эффектом.
- Неизвестный блок, лишние поля, порог там, где он не нужен (и наоборот), больше двух
  действий — отказ схемы/контракта, Studio показывает понятную причину; сервер не
  сохраняет такой черновик (400).
- Лимиты бюджета: на бойца ≤8 авто-способностей × (1+2 действия) + основная (1+2);
  в худшем случае 10 бойцов × 27 эффектов на шаг, 900 шагов — структурный предел.
- Старые бои воспроизводятся одинаково: без новых полей поведение не меняется
  (все прежние тесты боя проходят без изменений).
