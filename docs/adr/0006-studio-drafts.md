# ADR 0006: черновики Studio — подготовка S09

Статус: предложение, не реализация. Черновик имеет UUID и revision, данные
контента следуют общей схеме content v1. Сохранение должно выполняться отдельной
транзакцией PostgreSQL, под owner session, Origin и CSRF из S08, с аудитом.
Изменение revision должно быть условным: при несовпадении вернуть 409 и сохранить
обе версии для явного разрешения конфликта пользователем. Черновики не должны
менять опубликованный контент; публикация остается отдельным этапом S15.

Схема studio_draft.schema.json — только заготовка. Она еще не зарегистрирована
в validator и не используется клиентом или сервером. API, миграции, diff и UI
нужно реализовать и проверить до завершения этапа. Никаких данных VPS нет.
