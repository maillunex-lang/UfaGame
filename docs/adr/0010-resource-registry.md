# ADR 0010: предварительный реестр изображений

Статус: частичная реализация S11. Внутренняя модель PNG-ресурса содержит стабильный
id, SHA-256 исходных байт, размеры, указанные владельцем лицензию и атрибуцию,
масштаб, точку привязки, список прямоугольных кадров и loop. Кадры и anchor
обязаны находиться внутри изображения; лимит 120 кадров. Это отдельная схема,
она не добавляет ресурсную клиентскую capability и не меняет content v1.

ResourceRegistry — только память процесса; хранит собственные копии байт,
не более 128 ресурсов и 32 МиБ, 8 МиБ на файл. PNG проверяется в отдельном
Node-процессе с ограничением входа, времени, двух одновременных процессов,
V8 heap и Node permission для чтения конкретных файлов. Это не полноценная
изоляция ОС: сетевые и нативные ресурсы не ограничены ОС sandbox. Поддерживается
только ограниченное нечересстрочное 8-битное подмножество PNG, другие форматы
должны явно отклоняться. Фреймы восстанавливаются, проверяются CRC и лимиты.
Реестр пока не подключен к API/БД/UI, после перезапуска теряется; лицензии не
подтверждаются автоматически. Лимиты и формат подлежат нагрузочной проверке.
