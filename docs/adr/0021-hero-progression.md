# ADR 0021: герои игрока — уровни, ранги, пятёрка, синхронизация, экипировка (S23/S24/S28)

Статус: принято. Capability `heroes.progression.v1`. Числа таблицы — предложения
(`proposed`), владелец меняет их в Studio без нового APK.

- Контент: единственная таблица `progression` (цена уровня = база + прирост×(ур−1)
  золотом и `hero_exp`; рост характеристик `growth_bp` за уровень; ранги 1–20 с
  пределом уровня, числом копий и бонусом; `material_per_copy`; `sync_slots`;
  стартовые герои/предметы). `item` получает `stats`, `rarity`, `faction_ids`
  (совместимость), `upgrade_max/bp/gold`. У `stage`: `enemy_level`,
  `rewards_first_heroes/items`, валюты наград `hero_exp`, `rank_material`.
- Состояние игрока (миграция 013): экземпляры `player_heroes` (уровень, ранг, защита,
  `consumed_at`), `player_team` (main 0–4, sync 0–19; экземпляр в одном месте),
  `player_items` (улучшение, `equipped_on`; уникальность «один предмет на слот героя»,
  строка предмета принадлежит максимум одному герою). Выдачи идемпотентны по
  `source_key`.
- Траты: каждое действие несёт ожидаемое состояние (`from_level/from_rank/from_upgrade`),
  выполняется под блокировкой игрока и платит через ledger с ключом от этого состояния —
  двойное нажатие и гонки не тратят дважды (409 `STALE_STATE`).
- Уровень растёт только у основной пятёрки до предела ранга. Ранг: копии того же героя
  (не в команде, не защищённые, без предметов, свои), недостающие — материалами.
- Синхронизация: при полной пятёрке герой в ячейке получает минимальный уровень пятёрки,
  но не выше предела своего ранга; при неполной пятёрке выключена. Свой уровень героя
  не меняется (опыт не копируется); смена пятёрки пересчитывает только эффективный уровень.
- Характеристики: база×(1+рост×(ур−1)+бонус ранга) + бонусы предметов×(1+улучш×bp),
  целые, с пределами ядра. Считает сервер (`packages/battle-core/progression.mjs`).
- Бой: при наличии таблицы клиент присылает `instance_ids` (свои герои), `hero_ids`
  → 409 `ROSTER_REQUIRED`. Модификаторы закрепляются в бою (`attacker_mods`), повтор
  мгновенного боя пересчитывается с ними. Без таблицы всё работает по-старому.
- Удалённый из контента герой/предмет остаётся у игрока, но недоступен для боя.
