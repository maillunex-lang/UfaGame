# ADR 0014: неизменяемые версии контента, указатель публикации и откат (S15)

Статус: принято для тестового канала `test`. Миграция 009.

- `content_versions`: снимок черновика (content + дескрипторы ресурсов), SHA-256
  канонического JSON без поля content_version, `required_capabilities`, источник
  (draft id + ревизия). Метка `pub_NNNNNN` выдается сервером и записывается в
  `content.content_version`. Строки неизменяемы: триггер запрещает UPDATE/DELETE.
- `resource_blobs`: байты ресурсов по SHA-256, тип из проверенного дескриптора;
  тоже неизменяемы. Клиент скачивает ресурс по хешу один раз (immutable cache).
- `content_pointer` (канал `test`): активная версия и ревизия указателя.
  `content_releases`: журнал publish/rollback с причиной и request_id (неизменяем).
- Публикация (`POST /admin/v1/drafts/:id/publish`): одна транзакция — блокировка
  владельца, advisory lock публикации, проверка ревизии указателя
  (`expected_pointer_revision`, иначе 409 `POINTER_CHANGED`), ревизии черновика,
  сборка снимка, вставка blobs/версии, переключение указателя, журнал и audit.
  Любой сбой откатывает все: неполная версия не становится активной. Тот же снимок
  повторно — 409 `NO_CHANGES`. Повтор request_id — прежний ответ.
- Preflight (`.../publish/preflight`) только читает: проблемы, предупреждения
  (например герой без боевых параметров), дифф по объектам с активной версией.
- Возврат (`POST /admin/v1/content/pointer`): указатель на существующую
  совместимую версию с проверкой ревизии; журнал и audit. Возврат указателя не
  отменяет начисления/ledger — компенсации относятся к S46.
- Клиент (`GET /v1/content/current`, гостевой bearer): обязательный заголовок
  `X-Ufa-Capabilities`; если версии нужна неизвестная клиенту capability — 409
  `INCOMPATIBLE_CLIENT:<список>` (клиент не получает частично понятный комплект).
  Ответ — целый `content_bundle` с ETag=sha256 (304 при совпадении). Ресурсы —
  `GET /v1/content/blobs/:sha256`.
- Изменения состояния игроков при публикации (миграции прогресса) не выполняются
  автоматически; планируются отдельно (S46/S47).
