# ADR 0001: ограниченный прототип S01

Дата: 2026-11-02 UTC. Статус: provisional; Android-экспорт blocked.

Godot 4.6.3 official / GDScript / Compatibility: доступен и исполнил прототип.
Серверная запись создается Node 24.19.0 без зависимостей; это fixture, не API,
не WebSocket и не расчет боя. Продакшен-контракт остается задачей S03/S18.
Node/Fastify/TypeScript, React и PostgreSQL остаются предложением архитектуры;
их интеграция не проверена. PostgreSQL 18 — только кандидат, не установлен.
Не добавляем фиктивный dependency lock для отсутствующих зависимостей.
Точные использованные и предлагаемые версии: tools/s01/versions.json.

Для первой проверки: Android 8.0 / minSdk 26, targetSdk 35, только arm64-v8a.
Это инженерные значения, совместимость с телефоном владельца не подтверждена.
Package прототипа org.ufagame.game.s01 изолирован от будущих приложений.
Предлагаемые production IDs org.ufagame.game и org.ufagame.studio пока не заняты
реализованными приложениями; проверить окончательно на S04/S10.
Используем обычный экспорт APK без Gradle/custom Kotlin в S01.
JDK 17 рекомендуется официальной документацией; имеющийся Java 21 runtime
не содержит javac и не подтверждает готовность JDK к Android-сборке.
Android SDK: platform 35, build-tools 35.0.1; полный рекомендуемый набор
включает NDK 28.1.13356709/CMake 3.10.2.4988404, даже если обычному
экспорту без Gradle они не понадобятся. SDK и templates в среде отсутствуют.

Жесткий бюджет распространяемого APK: <=95 000 000 байт (десятичные МБ).
Предлагаемый внутренний бюджет: engine/native <=65 МБ, bootstrap/fonts <=20 МБ,
резерв <=10 МБ; это распределение цели, а не измерения. Внешние ресурсы отдельно.
Debug APK измерять отдельно, окончательный бюджет проверять на release APK.
Размер APK пока неизвестен. Если превышен бюджет — исследовать export template,
не подменять APK размером ZIP исходников.

Ресурсы прототипа: user://s01-assets/<sha256>, проверка hash до записи,
повторное использование, repair поврежденного файла, .part + rename.
На Linux сохранность между процессами подтверждена. Путь Android filesDir,
перезапуск/force-stop/update приложения требуют проверки на устройстве.
Нет eviction, сети, resume, проверки свободного места, fsync или production
активации версий: они остаются S16/S47/S49. Локальная запись не дает наград.

Источники: официальная ветка godot-docs 4.6, полученная через GitHub API
2026-11-02: https://github.com/godotengine/godot-docs/blob/4.6/tutorials/export/exporting_for_android.rst
Документ рекомендует JDK17, SDK35/build-tools35.0.1 и один ABI для экономии APK.
Другие источники: https://docs.godotengine.org/en/4.6/tutorials/io/data_paths.html
и https://docs.godotengine.org/en/4.6/tutorials/export/command_line_export.html
(эти две страницы в текущем сеансе повторно не получены; Android-путь
не считаем доказанным ссылкой). Текущие версии React/Fastify/PostgreSQL
по официальным источникам пока не перепроверены; стек окончательно не принят.

Откат: удалить только добавленные файлы S01; БД/сервисы/порты не менялись.
Данные прототипа находятся отдельно от будущего прогресса игры.


## Проверка после установки инструментов, 2026-11-02 UTC
Android-экспорт подтвержден чистой сборкой. Исходный preset был ошибочен:
min/target SDK override требует Gradle, а ETC2/ASTC import должен быть включен.
Исправлено: обычный template export, пустые overrides, mobile texture import.
Фактически aapt подтверждает minSdk24 (Android7.0), targetSdk36 и arm64-v8a.
Для S01 принимаем defaults шаблона; исходное предложение min26/target35
заменено этими измеренными значениями. Минимальный production Android
еще можно поднять после проверки приемочного телефона.
JDK Temurin17.0.21+9, SDK36/build-tools36.0.0, command-line19.0,
platform-tools37.0.1. SDK35/build-tools35.0.1 тоже установлены.
NDK/CMake для выполненного template export не понадобились.
Debug APK: 27 587 539 байт, ниже 95 000 000; подпись v2/v3 проверена.
Ограничения runtime на Android/остальных компонентов стека остаются.


## Продолжение стека и CI
Node24.19.0 + Fastify5.12.8 + TypeScript7.0.2 исполнили smoke/compile,
PostgreSQL18.4 — временный SQL smoke без сети/host ports. Для S01 принимаем
этот набор как проверенную техническую основу, production API остается S05.
React19.3.1 проверен только import/createElement, полноценный редактор — S09.
JS lockfile: tools/s01/stack-check/package-lock.json; образ PG pinned digest.
Pre-release APK опубликован GitHub Actions, подписан новым временным debug key.
SHA256 опубликованного артефакта c094eb81c3ff51008420d63134ff184e60597e56dba0837b7f4c97e5aad379a8.
Это отдельная CI-сборка, старый локальный APK не заменялся и не выдавался за нее.
Релиз одноразовый и не перезаписывается, постоянный release signing — S04.
Приемка на Android по-прежнему blocked; S01 не done.
