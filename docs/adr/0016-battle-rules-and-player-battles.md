# ADR 0016: правила способностей и серверный бой игрока (завершение S17)

Статус: принято. Дополняет ADR 0009 (шаг 100 мс, 900 шагов, 2+3) и ADR 0012 (сборка
из контента).

## Правила способностей (battle.abilities.v2)
- `ability.data.effect`: damage, heal, stun, knockback. Неизвестный эффект
  отвергается схемой контента и схемой снимка.
- `ability.data.target`: enemy (ближайший; по умолчанию для урона/контроля),
  weakest_enemy (наименьшее текущее HP среди врагов в радиусе, затем id),
  all_enemies (все враги в радиусе, по id; если нет — ближайший), ally_lowest
  (наименьшая доля HP, затем id; по умолчанию для лечения), self.
- stun: `power` в контенте — миллисекунды, ядро — шаги `ceil(ms/100)`, максимум 50
  (5 с). Оглушенный не двигается и не действует до `stunned_until_step`, энергия
  копится. knockback: `power` — расстояние (≤5000) от источника по x, ограничено
  полем 0..10000.
- Перезарядка основной способности `cooldown_ms` теперь действует
  (`cooldown_steps`); ранее (ADR 0012) не использовалась.
- `faction.data.advantage_bp` (10000–20000) — сила преимущества фракции; иначе 12000.

## Порядок событий шага
1) энергия; 2) оглушенные пропускают ход; 3) выбор ближайшего врага (seed при
равенстве); 4) движение, если враг вне радиуса; 5) авто-способности по интервалу;
6) атака/основная способность по интервалу атаки; 7) урон и лечение суммируются и
применяются одновременно; 8) оглушение и отбрасывание — только выжившим, порядок
эффектов не влияет на результат; 9) итог: оба погибли/таймаут 900 шагов — поражение
атакующего.

## Бой игрока
`POST /v1/battles` (гостевой bearer, лимит 30/мин): клиент передает только
`request_id`, `stage_id`, `hero_ids` (1–5); результат, seed и любые другие поля
отвергаются схемой. Сервер берет текущую опубликованную версию (закрепляет ее за
боем), выбирает seed (crypto), считает бой в worker thread (лимиты памяти, таймаут
5 с, не больше 2 одновременно — 503 `BATTLE_BUSY/BATTLE_TIMEOUT`) и сохраняет
`battles` (миграция 010). Повтор `request_id` возвращает тот же бой; другой payload —
409. `GET /v1/battles/:id` — только свой бой; при выдаче бой пересчитывается из
закрепленной версии и seed, хеш журнала обязан совпасть (иначе 500
`REPLAY_MISMATCH`). Наград нет (`rewards: []`): они относятся к кампании S22/S23.
Владение героями пока не проверяется — любые герои опубликованной версии (S24/S27).

## Бюджет
Структурно: ≤10 бойцов, ≤900 шагов, ≤90 эффектов на шаг. Локально: 5×5 с массовыми
оглушениями/отбрасываниями каждый шаг — ~45 тыс. событий за ~265 мс; обычный бой —
десятки мс. Замер на VPS — S54.
