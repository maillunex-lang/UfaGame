# S51: первичное обследование VPS

Эти команды выполняешь ты в SSH-сессии на VPS. Они только читают состояние:
ничего не устанавливают, не запускают и не останавливают. Проверку host key при
SSH не отключать; fingerprint сверить по доверенному каналу у провайдера.

```bash
hostname
uname -a
cat /etc/os-release
uptime
free -h
df -h /
df -i /
```

Слушающие порты и службы (8055 пока только предположение):

```bash
ss -lntup
systemctl --type=service --state=running --no-pager
```

Контейнеры и опубликованные порты, если Docker установлен:

```bash
if command -v docker >/dev/null; then
  docker ps --format 'table {{.Names}}\t{{.Image}}\t{{.Ports}}\t{{.Status}}'
  docker network ls
  docker volume ls
else
  echo 'Docker не установлен'
fi
```

Проверка рабочего портала без вывода cookies и тела ответа:

```bash
curl -sS -o /dev/null -w 'HTTPS статус: %{http_code}\n' https://tts-ufa.ru/
```

Не присылай содержимое .env, конфигураций с паролями, ключей, токенов, дампов
или логов личных сообщений. Результаты команд могут содержать имена проектов,
пути и IP — просмотри перед отправкой. Если какой-то команды нет или доступ
запрещён, оставь текст ошибки: это тоже полезно для отчёта.

Порт 8055, доступность маршрута `/game/server/`, сертификат для новых маршрутов
и тип reverse proxy пока не подтверждены. Не создавай каталогов, конфигураций,
БД или контейнеров по этим инструкциям. После отчета будет подготовлен отдельный
план test, diff общей конфигурации и план отката с сохранением портала.
