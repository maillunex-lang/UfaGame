# Секреты и локальные данные

Репозиторий публичный. Никогда не добавлять SSH/private keys, пароли, токены, recovery codes, signing keystore, дампы БД, данные игроков и логи личных сообщений. Gitignore снижает риск случайного добавления; `git add -f` обходит его, поэтому проверки также запрещают чувствительные tracked paths.

`.env.example` содержит только пустые/несекретные параметры будущей локальной конфигурации S05; сейчас сервисы его не читают. Личные значения хранить в игнорируемом `.env`, секреты CI — в штатном secret store. Публичный APK и отчеты подписи/hash допустимы в Releases, приватный ключ подписи — нет. Постоянная подпись и backup ключа относятся к S04; S01 debug key временный.

`npm run check:secrets` использует gitleaks версии из .gitleaks-version со стандартными правилами и полным redaction. Проверяются текущие tracked/nonignored файлы и доступная Git-история. Генерируемые и игнорируемые файлы не копируются в скан исходников; history scan все равно проверяет старые коммиты. Рабочая временная копия скана удаляется после проверки. CI загружает историю целиком.

Сканер не гарантирует отсутствие всех секретов, не проверяет удаленные системы и содержимое APK/архивов. Не добавлять ignore/allowlist ради прохода проверки. При находке остановить публикацию, отозвать/сменить настоящий секрет через его владельца и отдельно решить очистку истории; обычное удаление файла не стирает старые коммиты. В отчетах публиковать только тип/путь и redacted результат.

VPS обследуется только на S51: read-only инвентаризация, сохранение существующих проектов и проверка занятых портов. Не менять firewall/SSH/общий proxy, не чистить Docker глобально. S02 не создает сервисы и не занимает порты.
