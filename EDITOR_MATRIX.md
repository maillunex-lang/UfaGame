# Матрица комбайна
Для каждой строки обязательны реальные CRUD, поиск, формы/визуальный редактор где уместно, ссылки и зависимости, ZIP import/export, проверки, preview, аудит и версионирование. Удаление используется по правилам компенсации и миграции; не физический каскад без плана.

| Область | Редактируемые данные | Предпросмотр / серверная проверка |
|---|---|---|
| UI | экраны, панели, кнопки, списки, слои, anchors, вложенность, bindings, actions | размеры телефона, safe area, неизвестные actions |
| Графика | изображения, атласы, кадры, эффекты, звуки, точки крепления | анимации, размеры, память, лицензии |
| Герои/враги | характеристики, фракции, роли, способности, рост, ранг, образы | итоговые параметры, зависимости |
| Способности | типы готовых действий, цели, условия, энергия, эффекты, порядок | симуляция, budget выполнения |
| Бой | позиции 2+3, длительность, скорости, лимиты, разрешение skip | детерминированный сценарий |
| География | республика, районы, города, реальные координаты и игровые проекции | иерархия и маршрут |
| Кампания | главы, этапы, боссы, составы врагов, открытия, награды | достижимость, циклы ссылок |
| Квесты/события | условия, счетчики, этапы, расписания, награды | повтор, границы времени |
| Развитие | опыт, уровни, ранги, копии, материалы, ячейки синхронизации | расход и пределы |
| Предметы | 6 слотов, совместимость, редкость, улучшения, эффекты | экипировка и снятие |
| Призыв | пулы, шансы, гарантии, осколки, стоимость | сумма шансов, счетчики |
| Экономика | валюты, источники/стоки, AFK, магазины и лимиты | ledger, защита повторов |
| VIP | пороги, бесплатные источники, покупки, привилегии, VIP 1 в обучении | любой VIP достижим без оплаты |
| Донат | валюта, наборы, подписка, пропуск, цены/сроки | тестовый/реальный режим, выдача |
| Арена | подбор, рейтинг, сезоны, защита, награды | гонки и сезонное закрытие |
| Гильдии | роли, лимиты, босс, магазин, валюта | права и конкурентные вклады |
| Чат | каналы, лимиты, жалобы, блокировки, фильтры | права и безопасный текст |
| Жители | характеры, VIP, расписания, прогресс, шаблоны, память | имитация событий, общая пауза |
| Игроки | поиск, карточка, блокировка, корректировки, почта | причина, ledger и аудит |
| Публикации | черновики, diff, проверки, версии, компенсации, rollback | полный план последствий |
| Эксплуатация | состояние задач, копии, журналы, ресурсные лимиты | не редактор shell-команд |
