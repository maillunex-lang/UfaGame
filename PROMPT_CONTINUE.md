# Промпт продолжения в другом ИИ
Ты продолжаешь UfaGame: https://github.com/maillunex-lang/UfaGame, ветка `main`.
Сначала прочитай docs/HANDOFF.md, AGENTS.md, roadmap.md (таблицу и последние записи),
PROJECT_SPEC.md, ARCHITECTURE.md, OPEN_DECISIONS.md и prompts/stages/S19.md.
Не начинай заново. S01–S18 done; следующий этап — S19, затем S20 и далее по
roadmap до конца. Выполняй этапы целиком, проверяй автоматически (unit, интеграция с
реальной PostgreSQL, браузер, настоящий Godot), после каждого этапа обновляй
roadmap.md и docs/reports, коммить и пушь в main. Команды для VPS — только в чат
владельцу. Каждый APK — в GitHub Releases с прямой ссылкой; ключи подписи просить
у владельца архивом в сессию, в git не класть.
