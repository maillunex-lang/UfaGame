# Промпт создания сервера
Ты разрабатываешь сервер онлайн-игры UfaGame. Прочитай весь согласованный комплект и выполни ближайший доступный серверный этап. Предложение: TypeScript/Fastify, PostgreSQL, отдельный battle-core и worker; версии проверить и закрепить.
Сервер авторитетен для времени, коллекции, VIP, боя, наград, призыва, AFK, арены, гильдий, чата и товаров. Транзакции, idempotency и ledger обязательны. Приватная БД, rate limit, понятные ошибки, версионированные API и схемы.
Бой: фиксированный шаг, seed/snapshot/version, события в реальном времени, ручные команды с проверкой порядка. Быстрое исполнение того же движка для разрешенного VIP 7 skip. Не доверять скорости и результату клиента.
Гость → логин/пароль; восстановление хешированным одноразовым секретом, отзыв сессий. Один владелец админки.
Контент immutable, активный version pointer, staged import, capabilities, публикация/компенсация и план совместимости. Версию активного боя удерживать.
Жители пока template/event-driven; память/отношения и безопасные переменные, живой heartbeat отдельно, адаптивно 10–30, нет новой инициативы при нуле живых игроков, без бесконечных bot-to-bot цепочек. Игровые действия через обычные правила, без фиктивных покупок.
Магазин первой версии тестовый; reale payment adapter - отдельный поздний этап с серверной проверкой, возвратами и сверкой.
VPS: обследование read-only → отчет → изолированное test → проверка → prod. Не выбирать порты до проверки, не трогать чужие сервисы/firewall/SSH/volumes. Сборку APK не размещать на игровом VPS без оценки.
Копии ежедневно и перед опасными изменениями, пока на VPS; restore в отдельную БД. Лимиты/ротация/health и контроль регрессии существующих проектов.

## Обязательное завершение каждого этапа
Изучи AGENTS.md и roadmap.md, выбери доступный этап из prompts/stages/. Выполни реализацию, проверь ее и ОТДЕЛЬНО обнови roadmap.md с доказательствами и следующим шагом. Не отмечай непроверенное done. Сохрани существующие изменения и не публикуй секреты. Если требуются новые механики, обнови контракт, capabilities, редактор, документацию и совместимость. Не заменяй реализацию макетом.
