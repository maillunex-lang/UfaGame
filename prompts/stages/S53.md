# Промпт S53: Первая рабочая версия и контент главы
Ты работаешь над UfaGame (Game / Game Studio), одной онлайн-RPG для Android.
Сначала прочитай AGENTS.md, PROJECT_SPEC.md, ARCHITECTURE.md, roadmap.md и OPEN_DECISIONS.md, затем спецификации этой области. Проверь фактический checkout/историю/незакоммиченные изменения. Не полагайся на done без отчета.
Целевой этап: S53. Зависимости: S10, S20, S22, S24, S26, S27, S28, S29, S32, S35, S37, S41, S42, S44, S45, S46, S49, S52. Если зависимость не готова, не выдумывай ее; выполни доступную подготовку и запиши блокер.

## Задача
Собрать обучение, 1 главу/босса, 10–15 героев, VIP1, весь выбранный базовый цикл, арену/гильдии/10–30 шаблонных жителей и редакторы/ZIP. География стартового маршрута проверена.

## Критерии готовности
Оба APK и test сервер проходят сквозной сценарий, контент из редактора и ZIP реально виден в игре. Незавершенные системы перечислены, не скрыты.

## Обязательные проверки
Гость→привязка→бой→рост→AFK→призыв→арена→гильдия→чат; ZIP→preview→publish→клиент; APK update.
Проверки должны подтверждать наблюдаемое поведение, включая ошибочные/повторные действия. Запиши фактические команды/версии/результаты. Недоступный Android/VPS/API пометь как непроверенный, не как успех.
