# Промпт S47: Безопасное обновление контента
Ты работаешь над UfaGame (Game / Game Studio), одной онлайн-RPG для Android.
Сначала прочитай AGENTS.md, PROJECT_SPEC.md, ARCHITECTURE.md, roadmap.md и OPEN_DECISIONS.md, затем спецификации этой области. Проверь фактический checkout/историю/незакоммиченные изменения. Не полагайся на done без отчета.
Целевой этап: S47. Зависимости: S15, S16, S18, S46. Если зависимость не готова, не выдумывай ее; выполни доступную подготовку и запиши блокер.

## Задача
Version negotiation, staged download, активация между действиями, обязательный возврат на вход, удержание старой версии активным боем.

## Критерии готовности
Нет смешанных версий экрана/боя, обновление не теряет результат, старые ресурсы освобождаются только после снятия ссылок.

## Обязательные проверки
Публикация во время боя/загрузки, нехватка места для двух версий, несовместимый APK.
Проверки должны подтверждать наблюдаемое поведение, включая ошибочные/повторные действия. Запиши фактические команды/версии/результаты. Недоступный Android/VPS/API пометь как непроверенный, не как успех.

## Порядок завершения
1. Заверши реализацию и относящиеся схемы/примеры/инструкции.
2. Выполни проверки, сохрани отчет в docs/reports/S47.md без секретов.
3. ОТДЕЛЬНО обнови roadmap.md: S47, результат, файлы, проверки, ограничения, миграции/откат, следующий доступный этап.
4. done допустим только при выполнении критериев. Иначе in_progress/blocked с точным остатком.
5. При доступе сохрани commit/push в разрешенный maillunex-lang/UfaGame, не перезаписывая чужую работу; укажи подтвержденный URL. Сам факт commit не означает deployment.
6. Кратко сообщи владельцу результат и следующий шаг. Не проси повторное подтверждение уже выбранных требований.

## Обязательное завершение каждого этапа
Изучи AGENTS.md и roadmap.md, выбери доступный этап из prompts/stages/. Выполни реализацию, проверь ее и ОТДЕЛЬНО обнови roadmap.md с доказательствами и следующим шагом. Не отмечай непроверенное done. Сохрани существующие изменения и не публикуй секреты. Если требуются новые механики, обнови контракт, capabilities, редактор, документацию и совместимость. Не заменяй реализацию макетом.
